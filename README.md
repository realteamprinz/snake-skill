## What is snake.skill?

A species-specific extension of paw.skill that adds deep reptile intelligence — feeding schedule optimization, shed cycle tracking, handling tolerance profiling, enclosure microclimate management, and behavior pattern recognition.

paw.skill knows your pet. snake.skill knows your SNAKE.

## Install

Requires [paw.skill](https://github.com/realteamprinz/paw-skill) as parent.

```bash
# OpenClaw
clawhub install realteamprinz/paw
clawhub install realteamprinz/snake

# Hermes
hermes skills install paw-skill
hermes skills install snake-skill

# Claude Code
claude install-skill https://github.com/realteamprinz/paw-skill
claude install-skill https://github.com/realteamprinz/snake-skill
```
